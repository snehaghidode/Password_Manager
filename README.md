This is a secure full-stack web application designed to store and manage user passwords. Built with React, Node.js, and Tailwind CSS, it allows users to register, log in, and safely save credentials for multiple accounts. Passwords are encrypted for security, and users can view, edit, or delete them anytime. The project also demonstrates authentication, CRUD operations, and responsive design. Deployed via Vercel for easy access.
Technologies-
1. React
2. Node.js
3. Express.js
